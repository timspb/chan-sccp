## Повышенная стабильность SCCP на нестабильных каналах связи

Данный форк проекта [timspb/chan-sccp](https://github.com/timspb/chan-sccp)
содержит улучшения надёжности телефонов Cisco SCCP при работе
через нестабильные сетевые соединения, включая VPN-каналы
и соединения с периодическими обрывами связи.

### Основные улучшения

- **Автоматическое восстановление регистрации** после временной потери TCP-соединения.
- **Очистка зависших SCCP-сессий**, препятствующих повторной регистрации телефона.
- **Улучшенная обработка переподключения**, когда телефон устанавливает новое соединение до полного закрытия старого.
- **Дополнительная синхронизация сессий**, снижающая вероятность конфликтов при регистрации.
- **Улучшенное управление ресурсами** устройств, сессий и рабочих потоков.
- **Снижение риска постоянного отказа регистрации**, требующего ручной перезагрузки телефона.

### Проверенная конфигурация

| Компонент | Конфигурация |
|---|---|
| АТС | FreePBX 17 |
| Asterisk | 22.11.0 |
| Драйвер | chan_sccp |
| Телефоны | Cisco 7912, Cisco 7937 |
| Сеть | Маршрутизируемое VPN-соединение |
| SCCP-устройства | 17 успешно зарегистрированных |

### Результаты испытаний

На телефоне Cisco 7912 проверены следующие сценарии:

- Принудительное закрытие TCP-соединения на стороне АТС.
- Блокировка TCP-трафика от АТС к телефону на 90 секунд.
- Автоматическое восстановление регистрации без ручной перезагрузки.
- Сохранение регистрации остальных SCCP-устройств во время испытаний.

Оба сценария восстановления завершились успешно.

## Что нужно

- Сборка Asterisk с заголовками и файлами разработки
- Инструменты сборки: `gcc`, `make`, `autoconf`, `libtool`
- Библиотеки для XML и XSLT
- Библиотеки разработки OpenSSL
- `gettext`

Если в системе есть пакетный менеджер, сначала установите обычные dev-пакеты. Точные названия зависят от дистрибутива.

Пример для Debian / Ubuntu:

```bash
sudo apt update && sudo apt install -y build-essential git autoconf libtool pkg-config gettext \
  libxml2-dev libxslt1-dev libssl-dev libjansson-dev libsqlite3-dev
```

## Сборка из исходников

```bash
git clone https://github.com/timspb/chan-sccp.git
cd chan-sccp
./tools/bootstrap.sh
./configure
make -j2
make install
make reload
```

Если вы обновляете уже существующую копию:

```bash
git pull
./tools/bootstrap.sh
./configure
make -j2
make install
make reload
```

## Если что-то не работает

- Если `./configure` падает, проверьте установку dev-пакетов.
- Если сборка не находит заголовки Asterisk, установите matching Asterisk dev package для вашей версии.
- Если драйвер не загружается, сначала смотрите логи Asterisk и проверку модулей.
